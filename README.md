# 홈판 원고 스튜디오

네이버 홈피드용 블로그의 주제 리서치, 근거 정리, 제목·원고 작성, 이미지 생성, 발행 전 검수를 지원하는 단일 HTML 도구입니다.

## 컴퓨터에서 실행

1. 저장소의 **Code → Download ZIP**을 선택합니다.
2. 압축을 풀고 `index.html`을 더블클릭합니다.
3. 0번 패널에서 **OpenAI API 직접 연결**을 선택하고 API 키를 입력한 뒤 저장합니다.
4. **연결 테스트**, **웹 검색 테스트**로 사용 가능한 모델과 연결 상태를 확인합니다.

설치·외부 라이브러리·별도 서버가 필요하지 않습니다. API 작업에는 인터넷과 OpenAI API 이용 권한이 필요합니다.

## 주요 기능

- 제목 공식 분석 및 출처가 있는 주제 리서치
- 기사 근거 정리, 제목 5개, 블로그 원고 및 사진 자리 생성
- 이미지 자동 제작, 개별 재생성, PNG·ZIP 저장
- 근거와 원고를 대조하는 발행 전 검수
- 최근 원고 10개 보관 및 제목·본문 복사
- API 차단 시 대화 모드로 전환, 요청 복사 및 JSON 결과 가져오기
- 저비용 기본 텍스트 모델 `gpt-6-luna`, 이미지 모델 `gpt-image-2` / low
- 모델별 예상 건당 비용과 사용량 기반 텍스트 비용을 원화로 표시

## 비용·저장 안내

- 원화 표시의 기본 환율은 **1달러 = 1,400원**이라는 계산 예시이며 수정할 수 있습니다. 실시간 환율이 아닙니다.
- 텍스트 1건 예시는 입력 4,000 + 출력 2,000토큰 기준입니다. 검색·이미지·추론량·실제 분량 등에 따라 비용이 달라집니다.
- 단가는 2026-11-15 공식 요금표 기준입니다. 실제 청구는 달러 기준이고 세금·환전 수수료는 별도입니다.
- API 키는 입력한 브라우저의 localStorage에 저장되며 저장소에는 포함되어 있지 않습니다. 개인 PC에서 사용하고 필요하면 **키 지우기**를 누르세요.
- 생성 이미지 파일은 최근 원고 보관에 포함되지 않습니다. 창을 닫기 전에 PNG 또는 ZIP으로 저장하세요.

## 대화 모드

ChatGPT 미리보기처럼 직접 API 요청이 차단되는 환경에서는 요청을 대화로 보내거나 복사해 실행할 수 있습니다. 호스트가 대화 전송 기능을 제공하지 않으면 복사를 사용합니다. 답변의 JSON은 직접 붙여넣어 적용합니다. 자동 왕복 연결은 아닙니다. ChatGPT 대화의 사용 모델은 이 HTML의 API 모델 선택으로 변경되지 않습니다.

블로그 자동 발행 및 기사 사진 자동 다운로드는 지원하지 않습니다. AI 생성 이미지는 설명용 자료이며 실제 보도 사진으로 사용하지 마세요.
