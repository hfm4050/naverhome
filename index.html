API 키 설정

이 브라우저에서 OpenAI에 직접 연결합니다. 원고·검수도 API 이용료가 발생합니다.

처음 열거나 새로고침하면 GPT-6 Luna로 시작합니다. 이미지도 GPT Image 2 · low로 시작합니다. 다른 모델은 아래에서 선택해 현재 작업에 사용할 수 있습니다. API 키와 보관 원고는 유지됩니다.

이 대화로 작업 요청 · 결과 가져오기

1. 주제 찾기·원고 작성 버튼으로 요청 준비 → 2. 이 대화에 보내기 → 3. 답변의 JSON을 붙여넣고 적용. 결과가 자동으로 돌아오는 연결은 아닙니다.

건당 비용 · 예상치와 계산 기준

글 1건은 검색 없는 요청 1회, 입력 4,000 + 출력 2,000 토큰 가정입니다. 실제 분량·추론 토큰·검색 내용에 따라 달라집니다. 2026-11-15 공식 Standard / 짧은 컨텍스트 요금을 입력한 환율로 원화 환산했습니다. 실제 청구는 달러 기준이며 세금·환전 수수료는 제외합니다. 공식 요금표

개인 PC 전용
키는 이 브라우저의 localStorage에만 보관합니다. 공유 PC에서는 사용 후 지워 주세요. 파일 위치·브라우저에 따라 저장 공간이 달라질 수 있습니다.

최근 API 작업 · 검색 실행 기록
아직 실행한 검색이 없습니다. 실제 횟수는 응답의 web_search_call에서 집계합니다.

상한은 검색·페이지 열기·페이지 내 찾기를 포함한 웹 도구 호출 수입니다. 실제 검색 횟수는 action.type = search인 완료 항목 수이며, 내부 개별 질의 수나 과금 단위와 다를 수 있습니다. 자동 재시도는 하지 않습니다.

제목 또는 기사 URL 하나로 시작

근거 확인 → 제목 5개·원고 → 사진 자리별 이미지 → 최종 원고 적용. 2번의 분량·사진 수·말투를 사용하며, 전체 제작은 이미지 생성 비용도 발생합니다.
